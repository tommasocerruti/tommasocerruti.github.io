raw text and pseudocode only

(written without LLMs, but used LLMs to double-check, correct, or explain concepts)

title: Explaining Attention with Program Synthesis

authors: Amiri Hayes et al.

link: https://arxiv.org/abs/2606.19317

labels: interpretability, neural computation

problem: understanding computations performed by deep networks is hard.

current situation: neither top-down (training probes for human-defined concepts) nor bottom-up (generating summaries of the inputs that activate a feature/outputs that the feature promotes) are enough to provide a full formal description of neural computation.

proposal: explain computation through program synthesis, i.e., finding executable code that approximates the computation performed by components, which provide a middle-ground between billion-parameter models and natural language. furthermore, they are human-readable and formally verifiable, while also being able to be directly substituted for neural components.

focus: generating programmatic explanations of how attention heads compute attention weights in transformer LMs. for each attention head, extract a set of example attention maps on training examples, and prompt another LM to generate a set of candidate Python programs that can reproduce those attention maps given only input text. note: in the abstract they claim "replace the attention heads", but this overstates what is done, since a head also computes values and combines them using those weights, whereas what's being replaced is their attention matrices, retaining the value projections and weighted aggregation.

# shared computation
tokens = tokenize(input_text)
embeddings = embed(tokens)
hidden_states = preceding_layers(embeddings)  # including normalization
V = hidden_states x W_V

# neural route
Q = hidden_states x W_Q
K = hidden_states x W_K
attention_weights = softmax(Q x K_transpose / sqrt(head_dimension))

# OR programmatic route
attention_weights = program(input_text)

# shared aggregation
attention_outputs = attention_weights x V

result takeaway: across small scale llms (e.g., Llama-3B), the attention matrices of the best-matched 25% of heads can be replaced with programmatic ones, incurring only 16% average increase in perplexity, and no substantial effect on downstream question-answering performance.

method:

  1. record the ground-truth attention activation matrices of an LLM M (A_1, A_2, ..., A_n)
  2. provide another LLM S those ground truths prompting it to generate python code that could reproduce them
  3. execute them against some text, and score them against the ground truth using a proximity metric like JSD
  4. the top candidate (i.e., lowest JSD) is picked, and undergoes an additional round of feedback-conditioned refinement, i.e., showing S the examples where it performs best and worst, and revise the program (selected only if it performs better on held-out validation examples)
  5. for each head, select the best-fitting program from the whole program library for that model using IoU (which can be a program originally generated for another head).

evaluation:

  • attention alignment -- does the program produce attention matrices similar to the original ones? measured via intersection over union (IoU) between the synthetic programs and the neural patterns.
  • causal head replacement -- does the approximation preserve the model's behavior beyond being a simple proxy to resemble its patterns? measured via perplexity and task accuracy.

procedure (head replacement analysis):

  1. heads are replaced greedily in descending order of IoU score
  2. examining perplexity changes on the dataset processed by models with original heads and programmatic proxies (note: this is in-distribution evaluation, since it's the same dataset used to derive the programs)
  3. plot normalized perplexity increase (%) on the y-axis vs heads replaced (%) on the x-axis.
  4. evaluate OOD generalization on wide range of mcq reasoning tasks.

interesting takeaways:

  • great difference between encoder-only and decoder-only models: encoder-only programs are much harder to synthesize. this is likely due to the masked language modelling objective that produces bidirectional attention distributions that are more complex than the next-token prediction objective. in particular, IoU: BERT 33.95% vs. Llama-3.2-3B 79.42%. important note: BERT is the only encoder tried.
  • IoU scores monotonically increase with model scale. this likely reflects functional specialization at scale: individual heads serve narrower and more tractable roles.
  • positional programs dominate early layers, while syntactic programs account for a larger share of middle-layer assignments.
  • IoU scores are indeed good proxy metrics for functionality (Spearman correlation < -0.9 with perplexity increase for the three decoder-only models)
  • OOD downstream task performance is not monotonically decreasing with programmatic coverage

limitation:

  • no model's attention heads are fully characterized
  • preserving task performance alone cannot distinguish "we understood this computation" from "we don't need this computation"
